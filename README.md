# Personal Portfolio Website

## About the Project

This is a responsive and accessible personal portfolio website developed using HTML5, CSS3, Bootstrap, and JavaScript (ES6+).

The website presents my personal profile, academic background, technical skills, projects, achievements, and contact information in a simple and professional way.

## Technologies Used

* HTML5
* CSS3
* Bootstrap
* JavaScript (ES6+)

## Features

* Responsive design
* Navigation bar
* About Me section
* Education section
* Technical Skills section
* Projects section
* Achievements section
* Contact form
* Smooth scrolling
* Mobile-friendly navigation
* Interactive JavaScript features
* Accessible and semantic HTML structure

## Project Structure

```text
portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. The portfolio will open in your web browser.

## JavaScript Features

The `script.js` file provides:

* Mobile navigation menu
* Smooth scrolling between sections
* Contact form interaction
* Dynamic copyright year

## Responsive Design

The website is designed to work on:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

## Accessibility

The portfolio uses semantic HTML elements, readable text, proper navigation, and responsive layouts to improve accessibility and usability.
